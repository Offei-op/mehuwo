# Independent assessment planning sheet

Complete after the curriculum unit and reference skills have been reviewed.
This is a planning template, not a ready-to-administer validated assessment.

Specify before collection:

- How task scores become the binary per-skill judgment required by the app.
- What counts as insufficient evidence, an ambiguous answer or non-participation.
  Retain missing judgments as missing; do not substitute a zero or guessed mastery.
- Which instructions may be read aloud and how prompting is kept consistent.
- How responses, scorer disagreements and accommodations will be recorded.
- How the assessor will remain unaware of diagnostic outputs until judgments are saved.
- Assessment dates, ordering and any intervening teaching or practice.

Check that tasks do not duplicate diagnostic questions merely with new identifiers.
The app can check identifier overlap, but the expert must check content independence.
